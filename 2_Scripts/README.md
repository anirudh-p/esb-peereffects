# 2_Scripts

Scripts for data construction, preliminaries, and estimation.

- `config.py`: shared Python paths and constants.
- `run_preparation.py`: runs the preparation scripts in order.
- `run_stata_estimation.bat`: launches Stata using the local Stata executable.
- `1_Preparation/`: raw-to-cleaned data pipeline.
- `2_Preliminaries/`: descriptive statistics, balance checks, and preliminary figures.
- `3_Estimation/`: Stata estimation spine for the Brown pitch.
