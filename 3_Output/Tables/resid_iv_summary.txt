PROPENSITY-SCORE RESIDUALIZED IV: SUMMARY
======================================================================

MOTIVATION
----------------------------------------
The EPA CSB Program lottery is stratified by priority status
(high-poverty, rural, tribal) and state. Priority applicants
had ~12% win rate vs ~43% for non-priority. The original
spatial IV (w_geo_z) inherits this confounding, causing it to
predict district characteristics (5/8 balance test failures).

FIX: Residualize IV_Z on (is_priority x state) cell means,
then recompute spatial lag. Also add spatial controls for
neighbor application rates and priority status.

INTERPRETATION
----------------------------------------
Compare balance failures across instrument types.
If residualized IV passes balance but original fails,
the stratified lottery was the source of confounding.
If the peer effect estimate changes substantially,
the original estimate was biased by confounding.
If F-stat drops below 10, residualization weakened
the instrument too much.
