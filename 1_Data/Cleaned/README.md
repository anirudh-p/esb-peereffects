# Cleaned Data

Script-created datasets belong here. Expected core outputs:

- `analysis_district_panel.dta`: district-year or district-period hazard panel for Stata.
- `analysis_district_panel.csv`: CSV mirror of the main panel, if useful for inspection.
- `spatial_weights.*`: fixed neighbor weights used to construct spillover exposure.
- `build_diagnostics.csv`: sample, merge, and coverage diagnostics.

This folder is ignored by Git except for this README.
