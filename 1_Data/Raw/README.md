# Raw Data

This folder contains original source materials used to build the analysis datasets.

## Source Groups

- `WRI`: ESB adoption, grants, rebates, applicant, and survey materials.
- `Spatial`: district boundary and geography files.
- `Climate`: climate and terrain source files.
- `Political`: county presidential returns and source notes.
- `Other`: auxiliary crosswalks and infrastructure files.

## Updating Notes

For each new raw file, record:

- source institution or contact;
- original filename;
- date received or downloaded;
- brief description;
- redistribution restrictions, if any.
